# Velaris Pricing Tiers: Strategy & Rationale

## Executive Summary

Velaris uses a 3-tier pricing model designed around **behavioral science principles** to maximize conversion while delivering genuine value. The core strategy is "Show the Problem, Sell the Solution" - free users see their complete AI visibility issues across all platforms, but must upgrade to access the fixes.

## The Psychology Behind Our Pricing

### 1. "High-Value Acquisition" Strategy

**Problem:** Most freemium products limit features, reducing perceived value and urgency.

**Our Approach:** Free tier sees the **FULL PROBLEM**:
- All 3 AI platforms (ChatGPT, Gemini, Perplexity)
- Full customer journey (Awareness → Consideration → Decision)
- Real search data and actual AI responses
- Complete visibility score and competitive leaderboard

**The Gate:** Free users see "7 issues found" but cannot see the specific fixes. This creates:
- **Sunk cost effect** - Already invested time in analysis
- **Loss aversion** - Seeing problems without solutions is painful
- **Curiosity gap** - "What are my 7 issues?"

### 2. Anchoring Effect

Partner tier ($349) anchors perception, making Growth ($149) feel reasonable.

**Market comparison:**
- Semrush Pro: $129/mo
- Ahrefs Standard: $199/mo
- Moz Pro: $99/mo
- **Market average: $337/mo**

Velaris Growth at $149/mo is **56% below market average** while offering unique AI visibility features competitors don't have.

### 3. Decoy Effect

The one-time report ($199) makes monthly subscription ($149) attractive:
- "Why pay $199 once when $149/month gives unlimited analyses?"

## Implementation Notes

### Stripe Integration

```typescript
// Stripe Price IDs (placeholders)
professional_monthly: "price_professional_monthly"
professional_annual: "price_professional_annual"
partner_monthly: "price_partner_monthly"
partner_annual: "price_partner_annual"
```

### Tier Detection

User tier is stored in database and checked via `useTier()` hook:

```typescript
const { tier, limits } = useTier();

// Check feature access
if (!limits.showDetailedRecommendations) {
  openUpgradeModal("recommendations");
}
```

### Feature Flags

All limits are defined in `/lib/tier/types.ts` for centralized management.

## Summary

Velaris pricing is built on three principles:

1. **Show the Full Problem** - Free tier sees complete analysis across all platforms
2. **Gate the Solution** - Recommendations, deep dives, and exports require upgrade
3. **Price Below Market** - $149 is 56% below competitor average while offering unique value

This creates a natural conversion path:
> See problem → Feel urgency → Unlock solution → Measure improvement → Continue subscription
